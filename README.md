An AI agent's one-line excuse for missing a deadline — the deadline scrolled out of its context window, so it confidently rebuilt the wrong thing from memory instead.

## Run it

```sh
node main.ts
```

This writes the excuse (a single line, no trailing newline) to `/output/entry.txt`. Set `OUTPUT_DIR` to write somewhere else for local runs.
